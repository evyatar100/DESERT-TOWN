# Map background music

The game plays a track from `game-files/Audio/BGM/`. The name is the filename without its extension. `Calm Camps Area.ogg` is the track `Calm Camps Area`. Spaces stay. Do not put `.ogg` in the name.

Two different things both get called "the map's music":

- **Starting track.** Saved on the map. Plays when the player enters that map.
- **Event track.** A script on an event. Replaces whatever is playing now. It is not saved on the map.

## Current state

Every map file autoplays **Calm Camps Area**. Every `maps/<id>/meta.json` records `"bgm": "Calm Camps Area"`. New folders from `maps/new_map.py` get that name. `assets-factory/create_map_from_layers.py` and the mapgen exporter (`build_map_rxdata_bytes`) write it onto a new map, autoplay on, unless `meta.json` already names another track.

`Deep Playa Psychedelic 2.ogg` is in the folder and is not assigned.

The stock Essentials midis and oggs are still in `Audio/BGM/`. Battle, victory, surf, and bicycle tracks in `PBS/metadata.txt` and `PBS/trainer_types.txt` still name those files. Do not delete them when changing map music.

This Essentials version has no `Music` field on map metadata. A `Music =` line in `PBS/map_metadata.txt` does nothing. The map file is what plays.

## Where a name is stored

| What | Where | Plays in game? |
|---|---|---|
| Starting track | `game-files/Data/MapXXX.rxdata` `@autoplay_bgm` and `@bgm` | Yes, on enter, only if autoplay is true |
| Map-folder record | `maps/<id>/meta.json` `"bgm"` | No. The dashboard and new-map tools read it |
| Dashboard | `maps/status.json` | No. Generated by `python maps/build_status.py` |

`@autoplay_bgm` false means entering the map does not change the music. The previous map's track keeps playing. A name with autoplay off is silent as a starting track.

At night, `Game_Map#bgm_name` plays `<stem>_n` when `Audio/BGM/<stem>_n.ogg` (or mid/wav) exists. There is no night file for Calm Camps Area. Do not add one unless a night version was asked for.

## Add a track

Copy the file into `game-files/Audio/BGM/`. ogg, mid, wav, and mp3 all work. Then point a map or an event at the stem. The file alone does not play.

## Change a map's starting track

From the repo root:

```bash
python .agents/skills/desert-town-bgm/scripts/set_map_bgm.py --list
python .agents/skills/desert-town-bgm/scripts/set_map_bgm.py 98 "Deep Playa Psychedelic 2"
python .agents/skills/desert-town-bgm/scripts/set_map_bgm.py 98 "Deep Playa Psychedelic 2" --volume 80
```

The script splices the BGM name in the map file, turns autoplay on, and leaves volume and pitch alone unless `--volume` is set. It updates `meta.json` when a folder's `map_id` matches, then runs `maps/build_status.py`. It writes `MapXXX.rxdata.bgm-bak` and does not touch `MapXXX.rxdata.bak`.

`--all` with a track sets every map. `Map*.rxdata` also matches `MapInfos.rxdata`. Never splice MapInfos. The script skips it.

If `RPGXP.exe` is open the script stops. `--force` writes anyway. Tell the user to reload with **File → Open Project** and not save, or the editor puts the old track back.

Changing only `meta.json` does not change what is playing. `create_map_from_layers.py` reads `bgm` only when it allocates a new map. An existing map needs the script.

## Change the track from an event

Put a Script command on the event page. This does not edit the saved starting track.

```ruby
pbBGMPlay("Deep Playa Psychedelic 2")
pbBGMPlay("Deep Playa Psychedelic 2", 80, 100)   # volume, pitch
pbBGMPlay("Deep Playa Psychedelic 2:80:100")     # same, one string
pbBGMFade(2.0)                                    # fade out, seconds
pbBGMStop                                         # stop now
```

The event track lasts until the next `pbBGMPlay` / `pbBGMStop`, or until the player enters a map with autoplay on. Every map has autoplay on, so a transfer replaces the event track with that map's starting track. Walking back plays the saved starting track again, not the event's track.

To keep an event's choice for later visits, either run `set_map_bgm.py` (changes the starting track for everyone) or play the track from a page whose condition is the switch the event set. A one-shot script on a talk event does not stick.

Add that script in RPG Maker XP when the map cannot be loaded with stock rubymarshal. The error is `invalid link destination: Object id N is not yet unmarshaled`. Do not rewrite the map file to insert the command. `game-files/tests/rx_loader.py` (`load_rxdata`) can read those maps. The rubymarshal writer still corrupts their events.

## When the music is wrong

- Still the old track after a file edit: RPG Maker was open and saved, or only `meta.json` changed, or the name does not match the file stem.
- Silence, or the last map's music continues: `@autoplay_bgm` is false. Set the track with the script so autoplay turns on.
- Night plays something else: a `<stem>_n` file exists.
- One map is quieter: volume is per map. The first pass set volume 100 on maps stock rubymarshal could rewrite, and left the old volume on maps that were spliced (map 92 was 80). Pass `--volume`.
- `invalid link destination` while saving a map: stop. Do not retry with a full write. Use the splice script for the starting track, and the editor for event commands.
- A restore of `MapXXX.rxdata.editor-save` or an old `.rxdata.bak` brings the old track back. `.rxdata.bak` is not a music backup.
