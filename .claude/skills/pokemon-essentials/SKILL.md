# Pokemon Essentials v21 Development Skill

## Overview

Pokemon Essentials (PE) is a Pokemon fangame framework built on **RPG Maker XP** using the
**RGSS (Ruby Game Scripting System)**. This project uses **PE v21.1** running on **mkxp-z**
with **Ruby 3.1.0** (not the legacy Ruby 1.8 from vanilla RGSS).

> **CRITICAL**: This project uses `mkxp-z` with Ruby 3.1.0 (`x64-msvcrt-ruby310.dll`),
> NOT the original RGSS Ruby 1.8. You can use modern Ruby syntax including keyword arguments,
> string interpolation, symbol arrays `%i[]`, frozen string literals, etc. However, all code
> must still integrate with the RGSS API and PE's class hierarchy.

### Key Rules
- **NEVER edit files in `Data/`** — they are auto-generated by the compiler
- **ALWAYS edit PBS files in `PBS/`** — these are the source of truth for game data
- **Scripts live in `Plugins/`** — never modify `Scripts.rxdata` directly
- **Compile after PBS changes** — hold `Ctrl` while launching Game.exe, or use Debug menu → Recompile All

## PBS File Format

PBS files use an INI-like section format. Every entry starts with `[INTERNAL_NAME]` and
contains `Key = Value` pairs. Internal names are ALLCAPS with underscores.

### pokemon.txt — Species Definitions

```ini
[BULBASAUR]
Name = Bulbasaur
Types = GRASS,POISON
BaseStats = 45,49,49,45,65,65
# BaseStats order: HP, Attack, Defense, Speed, Sp.Atk, Sp.Def
GenderRatio = FemaleOneEighth
# Options: AlwaysMale, AlwaysFemale, FemaleOneEighth, Female25Percent,
#          Female50Percent, Female75Percent, FemaleSevenEighths, Genderless
GrowthRate = Parabolic
# Options: Fast, Medium, Slow, Parabolic, Erratic, Fluctuating
BaseExp = 64
EVs = SPECIAL_ATTACK,1
# Format: STAT_NAME,amount  (can list multiple: HP,1,SPEED,2)
CatchRate = 45
Happiness = 50
Abilities = OVERGROW
HiddenAbilities = CHLOROPHYLL
Moves = 1,TACKLE,1,GROWL,3,VINEWHIP,6,GROWTH,9,LEECHSEED
# Format: level,MOVE_ID pairs (comma-separated, all on one line)
TutorMoves = AMNESIA,ATTRACT,BIND,BODYSLAM,BULLETSEED
EggMoves = AMNESIA,CHARM,CURSE,GRASSYTERRAIN,INGRAIN
EggGroups = Monster,Grass
HatchSteps = 5120
Height = 0.7
Weight = 6.9
Color = Green
# Options: Red, Blue, Yellow, Green, Black, Brown, Purple, Gray, White, Pink
Shape = Quadruped
# Options: Head, Serpentine, Fins, HeadArms, HeadBase, BipedTail,
#          HeadLegs, Quadruped, Wings, Tentacles, MultiBody, MultiWings,
#          Bipedal, MultiHeadBody, Insectoid
Habitat = Grassland
Category = Seed
Pokedex = Bulbasaur can be seen napping in bright sunlight...
Generation = 1
Evolutions = IVYSAUR,Level,16
# Format: SPECIES,Method,Parameter
# Methods: Level, LevelMale, LevelFemale, LevelDay, LevelNight,
#          Item, ItemMale, ItemFemale, Trade, TradeItem,
#          Happiness, HappinessDay, HappinessNight, Beauty,
#          HasMove, HasMoveType, HasInParty, Location,
#          None (use pbEvolutionMethodAfterBattle)
```



### Scripting Conventions

#### Extending Existing Classes (Preferred Method)

```ruby
# GOOD: Reopen existing class and add/override methods
class Battle::Move
  # Add a new method
  def custom_effect(user, target)
    # your code
  end
end

# GOOD: Use alias to wrap existing methods
class Battle::Battler
  alias my_plugin_pbSuccessCheckAgainstTarget pbSuccessCheckAgainstTarget
  def pbSuccessCheckAgainstTarget(move, user, target)
    return false if some_custom_condition
    my_plugin_pbSuccessCheckAgainstTarget(move, user, target)
  end
end
```

#### DO NOT:
```ruby
# BAD: Never copy entire class definitions — always reopen
# BAD: Never hardcode numeric IDs — use symbols like :PIKACHU, :THUNDERBOLT
# BAD: Never edit files in Data/ — always use PBS or Plugins
```

## Common Scripting Tasks

### Working with Pokemon

```ruby
# Create a new Pokemon
pkmn = Pokemon.new(:PIKACHU, 25)    # species, level
pkmn.name = "Sparky"                 # nickname
pkmn.item = :LIGHTBALL               # held item
pkmn.shiny = true
pkmn.form = 0                        # form number

# Give the player a Pokemon
pbAddPokemon(:EEVEE, 10)

# Access player's party
$player.party.each do |pkmn|
  puts "#{pkmn.name} Lv.#{pkmn.level} HP:#{pkmn.hp}/#{pkmn.totalhp}"
end

# Check if player has a specific species
pbHasSpecies?(:PIKACHU)

# Heal all Pokemon
$player.party.each { |pkmn| pkmn.heal }
```

### Working with Items

```ruby
# Give items
pbReceiveItem(:MASTERBALL)
pbReceiveItem(:POTION, 5)          # give 5

# Check if player has item
$PokemonBag.has?(:MASTERBALL)

# Remove item
$PokemonBag.remove(:POTION, 1)
```

### Working with Game State

```ruby
# Switches (boolean)
$game_switches[42] = true
if $game_switches[42]
  # do something
end

# Variables (numeric/string)
$game_variables[10] = 42
$game_variables[10] += 1

# Badges
$player.badges[0] = true     # Give first badge
$player.badge_count           # Number of badges earned
```

### Battle Initiation

```ruby
# Wild battle
pbWildBattle(:PIKACHU, 25)

# Trainer battle
pbTrainerBattle(:LEADER_Brock, "Brock")
# With version number (for rematches)
pbTrainerBattle(:LEADER_Brock, "Brock", 1)

# Double battle
pbDoubleWildBattle(:PIKACHU, 25, :EEVEE, 20)
pbDoubleTrainerBattle(:TEAMROCKET_Grunt, "Grunt", 0,
                      :TEAMROCKET_Grunt, "Grunt", 1)
```

```ruby
# Transfer player to another map
pbTransferPlayer(mapID, x, y, direction)
```

### Creating Custom Move Effects

```ruby
# In Plugins/MyPlugin/moves.rb
# FunctionCode in PBS must match the class name suffix
class Battle::Move::MyCustomEffect < Battle::Move
  def pbEffectAgainstTarget(user, target)
    # Apply damage first (if damaging move)
    ret = super
    # Then apply effect
    if target.damageState.calcDamage > 0
      target.pbLowerStatStage(:DEFENSE, 1, user)
    end
    return ret
  end
end

# Then in PBS/moves.txt:
# [MYCUSTOMMOVE]
# Name = My Custom Move
# FunctionCode = MyCustomEffect
# ...
```

### Creating Custom Abilities

```ruby
# In Plugins/MyPlugin/abilities.rb
Battle::AbilityEffects::OnSwitchIn.add(:MYCUSTOMABILITY,
  proc { |ability, battler, battle, switch_in|
    battle.pbShowAbilitySplash(battler)
    battle.pbDisplay(_INTL("{1} activated its custom ability!", battler.pbThis))
    battle.pbHideAbilitySplash(battler)
  }
)

# Other ability hooks:
# Battle::AbilityEffects::DamageCalcFromUser
# Battle::AbilityEffects::DamageCalcFromTarget
# Battle::AbilityEffects::OnBeingHit
# Battle::AbilityEffects::EndOfRoundWeather
# Battle::AbilityEffects::OnEndOfUsingMove
# Battle::AbilityEffects::ModifyMoveBaseType
# Battle::AbilityEffects::OnSwitchOut
# Battle::AbilityEffects::StatusCheckNonIgnorable
```

### Creating Custom Items (Battle Use)

```ruby
# In Plugins/MyPlugin/items.rb
ItemHandlers::UseOnPokemon.add(:MYCUSTOMITEM, proc { |item, qty, pkmn, scene|
  if pkmn.hp == pkmn.totalhp
    scene.pbDisplay(_INTL("It won't have any effect."))
    next false
  end
  pkmn.hp += 50
  pkmn.hp = pkmn.totalhp if pkmn.hp > pkmn.totalhp
  scene.pbRefresh
  scene.pbDisplay(_INTL("{1}'s HP was restored.", pkmn.name))
  next true
})
```

## Battle System Architecture

### Damage Calculation Flow

```
1. pbCalcDamage(user, target)
2. → pbCalcBaseDamage(baseDmg, user, target)     # Base power modifiers
3. → pbCalcAttackStat(user, target)                # Attack stat used
4. → pbCalcDefenseStat(user, target)               # Defense stat used
5. → Apply type effectiveness
6. → Apply STAB (Same Type Attack Bonus)
7. → Apply random factor (85-100%)
8. → Apply critical hit multiplier
9. → Apply held item / ability modifiers
10. → Final damage dealt
```

### Key Battle Hooks (for Plugins)

```ruby
# Modify damage calculation
Battle::Move
  def pbBaseDamage(baseDmg, user, target)          # Override base power
  def pbCalcTypeMod(moveType, user, target)        # Override effectiveness
  def pbModifyDamage(damageMult, user, target)     # Multiply final damage

# Move success/failure
  def pbMoveFailed?(user, targets)                 # Check if move fails entirely
  def pbFailsAgainstTarget?(user, target, show_msg) # Fails vs specific target

# Additional effects
  def pbAdditionalEffect(user, target)             # Secondary effect (burn, etc.)
  def pbEffectAfterAllHits(user, target)           # After all multi-hit strikes
```

## Compilation Workflow

After editing PBS files, you must compile:

1. **Method 1**: Hold `Ctrl` while launching `Game.exe`
2. **Method 2**: In Debug mode, press `F9` → select "Recompile All"
3. **Method 3**: Delete the relevant `.dat` files from `Data/` and relaunch

### Recompile triggers:
- Any change to PBS `.txt` files
- Adding/removing plugins (delete `PluginScripts.rxdata` from `Data/`)
- Modifying `meta.txt` in any plugin folder

### Common Compilation Errors:
- **"Section name X already used"** — duplicate `[INTERNAL_NAME]` in PBS file
- **"Undefined method for nil"** — referencing an internal name that doesn't exist
- **"Expected Pokemon"** — wrong format in trainers.txt (check indentation)

## Debugging Tips

1. **Debug Mode**: Launch game normally (it auto-detects debug). Press `F9` for debug menu.
2. **Console Output**: mkxp-z opens a console window — use `puts` / `echoln` for logging.
3. **Error Log**: Check `errorlog.txt` in the project root after crashes.
4. **Backup before changes**: Always keep PBS backups (the project has Gen 5-8 backups).
5. **Test in isolation**: Create a test map with a debug event to test scripts.
