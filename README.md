# DESERT-TOWN

Welcome to **DESERT-TOWN**!

## Repository Structure

- **`game-files/`**: Contains the full RPG game codebase, assets, audio, plugins, and data derived from `RPG-midburn`.
- **`assets-factory/`**: Contains the asset processing toolset, pixel fixing scripts (`fix_tileset.py`, `fix_character.py`, `create_tileset.py`), and graphic manipulation utilities.
