TG5 Temple sticker boards: structure note (Dor, 2026-10-26; rev 2 after Rotem Pass 0 + QA PARTIAL; rev 3 phase 2: signs, reward, sheet art; rev 4 2026-10-26: home-board-only placement, Time-Warp carry; rev 5 2026-10-26: no dealt hand, signs give their own sticker, reward = one per board; rev 6 2026-10-26: half-sticker spots, overlap browsing).

Triggers: T1 (two new scenes), T2 (new save value + module state), T4 (new plugin, 4 deps).
1. UNITS (all in `game-files/Plugins/TempleStickers/`; one job each; file order = dependency order)
   - `000_data.rb` sticker/board tables, caps, `depth` (reads `DesertTownArcade.depth`), `data_dir`, `sign_key`, renamed-sticker aliases (`CURRY_HEEL` -> `CURRY_TOAST`).
   - `001_key_buffer.rb` keyboard tabs/layout + text buffer (charset, caps, delete/cancel).
   - `002_staff.rb` cfg parse, code match, code typeability check + non-secret warning, reward write-back, staff-active flag.
   - `003_run.rb` per-run state (no hand: collected + placed): normalize (drops an old `:hand`), collect (any sticker, once per run), `read_sign`, `placeable`, `placeable_on(board)` (home board only), `other_homes`, record placement (refused off the home board), `set_name`, `reward_earned?` (the one reward predicate, confirmed by founder 2026-10-26: a sticker on each of the 4 boards), `record_stored_placement` (crash recovery records the stored item's real board), `reward_due?`, `mark_reward_shown`; SaveData register.
   - `004_wall_store.rb` wall file (v3, items at half-cell spots `p`; v1/v2 cells migrate via `cell_to_spot`; a higher version is refused), spot geometry (`overlap?`, `stack_at` newest first, `move_spot`, `free_spot`): load/quarantine/.bak restore, atomic save, depth tabs + sheets, cap, `sign_item`; `TempleStickers.place` transaction.
   - `005_ui.rb` shared colours, `draw_text`, `silenced` (BGM), colour-button reads, staff combo.
   - `006_art.rb` sticker bitmaps: `Graphics/Pictures/TempleStickers/<honoree>.png` cells, placeholder shapes when missing. `007_keyboard_scene.rb` keyboard (optional `mask:`).
   - `007a_board_view.rb` board screen layout + drawing only (no state, no input): `Graphics/Pictures/TempleStickers/board_bg.png` (wall, pinned dotted paper, tray, info box, legend band; drawn plainly if missing), title, depth tabs, stickers at spots (`spot_origin`, half-cell steps), hand tray (4 slots; only this board's stickers, at most 3), info box (`draw_stack_info` lists overlapping stickers), button legend. Art and mockup come from `assets-factory/temple_board_art.py`.
   - `008_board_scene.rb` board state/input + what to show per mode; `pbTempleBoard(board)` asks "לוח של X. להתקרב?" first. Scene and keyboard viewports sit at z 99_999 (created after pbFadeOutIn's black layer, so drawn above it). `009_signs.rb` `pbTempleSign(id)`. `010_reward.rb` Ido's visit: `on_enter_map` arms it, `pbTempleMessenger(get_self)` on the Map096 `temple_messenger` event plays it. `011_debug.rb` F9 debug hook (kept for laptop tests). `012_temple_music.rb` `Music.carry_after`/`owns?` (pure) + `Game_Map#autoplay`/`autoplayAsCue` and `Scene_Map#autofade` wraps that keep Time-Warp on Map096 after the temple.
2. STATE
   - Run hash: owned by `003_run` (`$temple_stickers`), saved via SaveData. Writers: `collect` (via `read_sign`), `record_placement`, `set_name`, `mark_reward_shown` only.
   - Messenger pending flag: owned by `010_reward` (module ivar, not saved); set by `arm_messenger`, consumed once by `take_messenger`.
   - Wall hash: owned by `004_wall_store`; the board scene holds a loaded copy and edits it only through `WallStore` (`sign_item` for name/sentence) / `TempleStickers.place`.
   - Temple music carry: owned by `012_temple_music` (`$PokemonGlobal.temple_music_carry`, saved with the game); written only by its `on_leave_map` handler, read by its autoplay/autofade wraps.
   - Staff active flag: owned by `002_staff` (module ivar, not saved); `003_run.start_new_run` clears it.
   - Tabs: a tab = one Inception depth; all runs at that depth share it. Only the newest sheet of the current depth is writable; a full sheet (28 stickers, overlap allowed) opens the next sheet; items are stored oldest first, so drawing in order puts the newest on top. Pages sorted by [depth, sheet]; cap 300 per board drops the lowest depth first, never the page just written; trimmed on load too.
3. INTERFACE: the board scene calls `WallStore.load/target/save/delete_*`, `TempleStickers.place` (reverts on failed save), `KeyboardScene.new(prompt, max, prefill, mask:).run`, `Staff.read/matches?/warn_if_untypeable`. Staff entry: White+Green on the board opens a masked code keyboard; the name flow never checks codes. The scene never branches on a board id; it asks `placeable_on(run, board)` which hand stickers fit and passes only those to `BoardView.draw_hand`; with no fit the info box shows `TEMPLE_HAND_OTHER_BOARD`.
