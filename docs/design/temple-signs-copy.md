## Note

**Single-source flags (Michal) and fallbacks.** Neither changes the V fact in box 1.
- **CURRY_TICKET box 2** (qC4, "crazy"): one CBS interview, reprinted by People/AOL. If rejected, box 2 becomes:
  - HE: הקהל החזיק אותו בחיים. הוא מוקרן עד היום, כ-50 שנה אחרי.
  - EN: Audiences kept it alive. It is still shown, about 50 years later.
- **PARTON_SONG box 2** (qD4, "count my money"): first-hand GMA interview, one source. If rejected, the sign is box 1 alone (box 1 already ends on "kept them").

**Decisions**
- **Frank-N-Furter in Hebrew: פרנק נ. פורטר.** Maariv (article 1221754) and he.wikipedia both print it that way, with the period. The hyphenated draft פרנק-אן-פורטר appeared in neither. Only those two sources were checked.
- **Long boxes.** YONATH_BEAR box 2: no cut, tighter Hebrew only ("ועוד" for "even more"), 82 characters. CURRY_HEEL box 1: dropped "in high heels" (the sticker carries it) in both languages, 79 characters. PARTON_SONG box 2: tighter Hebrew, 79 characters.
- **Other trims** (facts only): KUSAMA_MIRROR box 2 expanded to "מוזיאון טייט בלונדון" (Michal's note); PARTON_NAILS box 1 uses "ציפורניה"; YONATH_KEY box 1 "מעל 20 אנטיביוטיקות"; PARTON_BOOK box 1 reordered.
- **One accuracy change in PARTON_SONG box 1, both languages.** Tamar's fact row P3 says Colonel Parker (Elvis's manager) demanded half the publishing rights; Michal's "Elvis wanted" blurred that. Revert to "Elvis wanted…" if preferred, but the Hebrew then runs to 3 lines.
- **Translations.** "He" in the CURRY_HEEL quote is Frank-N-Furter; box 1 ends on that name, so the Hebrew "הוא" resolves. "Try on for size" becomes the dressing-room idiom "למדוד… תפקידים". Yonath's original Hebrew for qY1/qY2 was not found; these are back-translations. "שוטת הכפר" is the feminine of the idiom שוטה הכפר.
- **May not land on a skim.** "ל'מדענית' כביכול" keeps the scare quotes of the English; "9 to 5" and "I Will Always Love You" stay in English inside the quotes.
