# Maps folder — agent & human conventions

This directory is the **source of truth** for Desert Town’s real game maps.
Essentials default / leftover maps in `game-files/Data` (Lappet Town, Cedolan, Battle Frontier, etc.) are **out of scope** — leave them alone.

## Layout

```
maps/
  AGENTS.md
  CONNECTOR_INTENTIONS.md  # world-app tool intentions
  world_layout.json    # outside map positions + multi-edge connections (world-app)
  status.json          # generated by build_status.py — commit after changes
  index.html           # GitHub Pages dashboard (reads status.json)
  _generic/            # shared tiles appended to every tileset
  <map-id>/
    meta.json          # required
    characters.json    # required (may be empty list)
    base.png           # Layer 1 — full map, ≥ 20×15 tiles (640×480 px), 32px grid
    layer2.png         # Layer 2 — same size as base (optional)
    layer3.png         # Layer 3 — same size as base (optional)
    layer3b.png        # extra L3 overlays (optional; painted onto Layer 3)
    tileset.png        # built 256px-wide sheet (optional until built)
    artifacts/         # gem-map-tool / desert-town-mapgen exports
    old/ …             # archives; ignored by tools
```

Outside-map world layout UI: `world-app/` (see `CONNECTOR_INTENTIONS.md`).

**1:1 rule:** one map folder ↔ one tileset (`{map-id}_ts` in game files).

## `meta.json`

```json
{
  "id": "kusomo",
  "display_name": "Kusumo",
  "map_id": 94,
  "tileset_name": "kusomo_ts",
  "is_outside": true,
  "bgm": null,
  "connections": { "north": null, "south": null, "east": null, "west": null },
  "status": "in_progress",
  "deprecated": false,
  "notes": ""
}
```

| Field | Meaning |
|---|---|
| `id` | Folder name |
| `display_name` | Human / in-game name |
| `map_id` | `MapXXX.rxdata` id, or `null` if not linked yet |
| `tileset_name` | Stem of PNG under `game-files/Graphics/Tilesets/` (no `.png`) |
| `is_outside` | Outdoor map? |
| `bgm` | BGM filename stem, or `null` |
| `connections` | Neighbor **map folder ids** (N/S/E/W) |
| `status` | `stub` \| `in_progress` \| `playable` \| `done` |
| `deprecated` | `true` hides the map from world-app and from `index.html` unless “Show deprecated” is checked. Omit or `false` for live maps. |

## `characters.json`

```json
[
  { "id": "npc_1", "name": "Aviad", "x": 10, "y": 12, "graphic": "NPC 01", "notes": "" }
]
```

Positions are tile coordinates on this map. Empty list `[]` is fine.

## Building tilesets & maps

From repo root:

```bash
# Tileset from standardized layers + maps/_generic
python assets-factory/create_tileset.py maps/kusomo -y

# Tileset + register MapXXX / Tilesets.rxdata (base→L1, layer2→L2, layer3+→L3)
python assets-factory/create_map_from_layers.py maps/kusomo
```

`create_tileset.py` concatenates `base` / `layer2` / `layer3` / `layer3b`… then appends `maps/_generic`. Use `--no-generic` to skip.

After changing map folders, refresh the dashboard:

```bash
python maps/build_status.py
```

## Status page

Open `maps/index.html` locally or via GitHub Pages (serve repo, path `/maps/`).
It loads `status.json` and shows readiness columns (base, L2, L3, tileset, in-game copy, map link, connections, events, chars).

## Agent rules

1. Prefer editing files under `maps/<id>/` over inventing parallel asset trees.
2. When you add/rename layers, update `meta.json` and run `build_status.py`.
3. Do not modify Essentials default maps unless explicitly asked.
4. Keep `old/` / archive subfolders; tools only read top-level standard names.
5. Copy built sheets to both `maps/<id>/tileset.png` and `game-files/Graphics/Tilesets/<tileset_name>.png` when deploying.
6. RPGXP map tools: `.agents/skills/rpgxp-map-tools/`. Mapgen app: `.agents/skills/desert-town-mapgen/`.
